1. Visão Geral do Sistema

O Lazarus Portable Manager é uma solução de orquestração avançada que transforma o Lazarus IDE em uma aplicação 100% portável, podendo ser executada a partir de qualquer unidade (Pen Drive, HD externo ou pasta local) em qualquer computador Windows — sem instalação prévia.

📌 Objetivo Central: Executar o Lazarus IDE completo (FPC, LCL, pacotes OPM, componentes personalizados e perfis de usuário) a partir de um Pen Drive ou HD externo em qualquer computador Windows, mantendo todas as configurações, layouts e atalhos intactos.

🧩 Módulos Internos

MóduloResponsabilidade
uPortableCoreMotor de patch de XMLs, backup/restore, gerência dos diretórios portáveis.
uPackageManagerVarredura de pacotes .lpk instalados, exportação JSON e integração com OPM online.
uProfileManagerCriação, ativação, salvamento e exclusão de perfis de configuração isolados.
uDiagnosticsDiagnóstico de 23+ pontos críticos do ambiente FPC/Lazarus com relatório exportável.
uLauncherLançamento do lazarus.exe com variáveis de ambiente portáveis e backup automático.
uLicenseManagerAutenticação, cadastro, trial de 10 dias, aprovação de PIX e comunicação com VPS Firebird.
uConfigCryptCriptografia XOR Hexadecimal do arquivo vps_config.ini com migração automática de INIs legados.
uPIXPayloadGeração do payload EMV Pix Copia e Cola e QR Code via API externa.

2. Tela de Login / Cadastro (frmLogin)

Ao iniciar o LazarusPortable.exe, a primeira tela exibida é o Formulário de Autenticação. Ela possui dois modos: Login e Cadastro, alternáveis pelo botão de modo.

💡 Ao abrir, o sistema verifica automaticamente o Trial local e exibe a mensagem de status abaixo do formulário (ex: "Período de testes: 8 dias restantes"). Ao carregar, os parâmetros de conexão VPS são lidos do arquivo LazarusConfig\vps_config.ini (criptografado).

🖱️ Botões da Tela de Login

BotãoModo AtivoAção Executada
🔑 Entrar com E-mail e Senha Login Autentica o usuário no banco Firebird VPS com e-mail e senha. Se aprovado, abre o painel principal (frmMain). Em caso de falha, exibe o motivo no campo de status e em um diálogo de aviso.
✨ Cadastrar e Ganhar 10 Dias Grátis Cadastro Registra novo usuário (nome, e-mail, senha) no banco Firebird VPS e inicia imediatamente o período trial de 10 dias completos. Após o cadastro bem-sucedido, o sistema entra automaticamente no painel principal.
Não tem conta? Cadastre-se e ganhe 10 dias grátis Login Alterna o formulário para o modo Cadastro, exibindo o campo "Nome Completo" e trocando o texto do botão de ação.
Já possui uma conta? Clique aqui para entrar Cadastro Alterna de volta para o modo Login, ocultando o campo de nome e reduzindo o formulário.
⏳ Continuar no Modo Trial Ambos Permite usar o sistema sem fazer login, desde que o trial (10 dias) ainda esteja ativo. Se o trial estiver expirado, exibe aviso e retorna à tela de login com mrCancel. Requer pagamento PIX para liberar acesso após a expiração.

7. Aba Pacotes (📦)

Exibe todos os pacotes .lpk instalados e registrados na instalação portável do Lazarus. A lista em modo relatório contém as colunas: Nome, Versão, Autor, Status e Caminho do arquivo .lpk.

🖱️ Botões da Aba Pacotes

BotãoAção Detalhada
🔄 Varrer Executa varredura completa lendo o packagefiles.xml da instalação portável e localizando todos os arquivos .lpk referenciados. Preenche a lista com nome, versão, autor, status e caminho. Pacotes com caminho inválido recebem o marcador ⚠️ na coluna Status. Exibe a contagem total abaixo da lista.
📤 Exportar Lista Abre um diálogo Salvar Arquivo para exportar a lista completa de pacotes em formato JSON (sugerindo o nome pacotes_lazarus.json). Útil para documentação, auditoria ou comparação entre diferentes ambientes de desenvolvimento.
🌐 OPM - Instalar Online Atalho que navega diretamente para a aba OPM Online, onde é possível pesquisar e baixar novos componentes da comunidade Lazarus sem sair do gerenciador.
💡 Estados dos Pacotes: psOK = arquivo .lpk encontrado e acessível. psPathBroken = arquivo não localizado no caminho registrado — execute 🔧 Re-Patch Config para corrigir os caminhos automaticamente.

8. Aba Perfis (👤)

Permite criar e gerenciar ambientes de trabalho completamente isolados para o Lazarus — cada perfil possui seus próprios pacotes, layouts de paleta, atalhos de teclado e configurações de compilador, sem misturar ou reinstalar a IDE.

A lista exibe: Nome (✅ para o perfil ativo), Descrição, Criado em e Último Uso.

💡 O que cada perfil armazena individualmente: pacotes e componentes instalados, layout de janelas e paletas, caminhos de compiladores, macros do editor, atalhos de teclado e lista de arquivos recentes.

🖱️ Botões da Aba Perfis

BotãoAção Detalhada
➕ Novo Perfil Solicita via caixa de diálogo o nome e uma descrição opcional para o novo perfil. Cria uma pasta vazia e isolada com esse nome em Profiles\[Nome]\ dentro do diretório portável. O novo perfil aparece imediatamente na lista com sua data de criação.
✅ Ativar Perfil Ativa o perfil selecionado na lista. Antes de prosseguir, exibe um diálogo de confirmação alertando que a operação sobrescreve a configuração atual do LazarusConfig\ com os arquivos do perfil escolhido. Após ativar, o perfil recebe o ícone ✅ e a data de "Último uso" é atualizada.
💾 Salvar Config Atual Solicita o nome de um perfil via diálogo e copia o estado atual completo da pasta LazarusConfig\ para Profiles\[NomeDoPerfil]\. Use após instalar novos componentes na IDE para "congelar" esse ambiente para uso futuro.
🗑 Deletar Remove permanentemente o perfil selecionado e todos os seus arquivos. Exige confirmação antes de excluir. Não é possível deletar o perfil atualmente ativo — uma mensagem de erro é exibida se tentado.

💡 Exemplos de Uso de Perfis

  • Por Cliente: "Cliente_A_ACBr" (ACBr + Fortes Reports instalados) vs "Cliente_B_REST" (componentes REST e JSON).
  • Por Ambiente: "Dev_Debug" (ferramentas de debug e logs ativos) vs "Release_Clean" (IDE limpa e rápida para compilação final).
  • Por Versão FPC: Um perfil configurado para FPC 3.2.2 e outro para FPC 3.2.4.
  • Por Plataforma: "Proj_Android_LAMW" vs "Proj_Windows_VCL".

9. Aba Pagamentos (💳)

Gerencia o histórico de comprovantes de pagamento PIX e permite ao Administrador aprovar ou rejeitar licenças. A lista em modo relatório exibe: ID, Data Envio, Usuário / Chave PIX, Valor Pago, Comprovante, Status Análise e Observação.

🖱️ Botões da Aba Pagamentos

BotãoVisível paraAção Detalhada
➕ Enviar PIX Todos Abre a Tela de Pagamento PIX (frmPayment) para gerar o código Copia e Cola / QR Code e enviar o comprovante de pagamento ao servidor VPS.
🔄 Atualizar Todos Recarrega a lista de comprovantes diretamente do banco de dados Firebird VPS, buscando novos registros enviados ou atualizações de status (ex: "Aprovado" ou "Rejeitado").
✅ Aprovar Licença (30 Dias) Admin Selecione um comprovante na lista e clique. Solicita uma observação (ex: "Pagamento PIX verificado e aprovado") e adiciona automaticamente 30 dias de licença ao usuário remetente, marcando o comprovante como "Aprovado" no banco. Botão visível somente para administradores.
❌ Rejeitar Comprovante Admin Selecione um comprovante e clique. Solicita o motivo da rejeição (ex: "Comprovante ilegível ou valor incorreto") e atualiza o status no banco para "Rejeitado" sem adicionar dias ao usuário. Botão visível somente para administradores.
👁️ Ver Comprovante Todos Abre o Visualizador de Comprovante (frmReceiptViewer) exibindo a imagem ou PDF do comprovante selecionado, baixado do servidor VPS.
💡 Duplo Clique na Lista: Fazer duplo clique em qualquer comprovante abre automaticamente o visualizador (frmReceiptViewer), equivalente ao botão "👁️ Ver Comprovante".
🔐 Visão do Administrador: Quando logado como admin, a coluna "Usuário / Chave PIX" exibe o nome completo e e-mail do usuário remetente. Os botões Aprovar e Rejeitar ficam visíveis apenas nesse modo.

💳 Tela de Pagamento PIX (frmPayment)

Aberta ao clicar em "➕ Enviar PIX" ou "💳 Renovar PIX". As informações de pagamento (chave PIX, valor, banco, titular) são carregadas automaticamente do servidor VPS. O payload EMV Copia e Cola é gerado pelo módulo uPIXPayload.

BotãoAção Detalhada
📋 Copiar Código PIX Copia o payload EMV PIX Copia e Cola para a área de transferência do Windows. Cole no aplicativo do banco para realizar o pagamento sem digitar. O QR Code exibido ao lado serve como alternativa para escanear com o celular.
📁 Selecionar Arquivo Abre um diálogo de seleção de arquivo para escolher o comprovante de pagamento (PDF, PNG, JPG ou qualquer formato de imagem). O caminho completo do arquivo selecionado é exibido no campo correspondente.
📤 Enviar Comprovante Faz o upload do arquivo selecionado para o servidor VPS via conexão Firebird, associando-o ao ID do usuário logado, à chave PIX e observações preenchidas. Após envio bem-sucedido, o comprovante entra na fila de análise do Administrador e a tela fecha com resultado OK.
💡 Sem conexão com a internet: O QR Code não será carregado (gerado via api.qrserver.com), mas o código Copia e Cola permanece 100% funcional para realizar o pagamento no banco.

10. Aba Diagnóstico (🔍)

O módulo uDiagnostics verifica 23+ pontos críticos da instalação portável, organizados por categoria, e exibe o resultado em lista com ícones de status. Colunas: Status (✅ ⚠️ ❌ ℹ️), Categoria, Verificação e Detalhe / Valor encontrado.

🖱️ Botões da Aba Diagnóstico

BotãoAção Detalhada
▶ Executar Inicia a varredura completa do ambiente. Verifica os seguintes pontos críticos:
  • Existência e acessibilidade de lazarus.exe e fpc.exe
  • Existência e integridade dos XMLs principais: environmentoptions.xml, packagefiles.xml, fpcdefines.xml
  • Presença e validade dos arquivos .lpk de pacotes referenciados
  • Configuração e acessibilidade da LCL (Library Control Library)
  • Configuração de variáveis de ambiente FPC (FPCDIR, LAZARUSDIR)
  • Espaço em disco disponível na unidade portável
  • Configurações de caminho no perfil ativo
  • Outros pontos de verificação específicos do ambiente portável
Ao terminar, exibe resumo colorido no rodapé: verde (tudo OK), amarelo (avisos), vermelho (erros críticos que impedem o funcionamento).
📄 Salvar Relatório Abre diálogo Salvar Arquivo para exportar o relatório completo em formato texto plano com timestamp no nome (ex: diagnostico_lazarus_20260717_104500.txt). Útil para suporte técnico ou registro histórico de ambiente.

11. Aba Log (📋)

Exibe o log completo e cronológico de todas as operações realizadas na sessão. Cada linha é prefixada com o horário e um indicador de nível:

  • [hh:nn:ss] — Timestamp de cada evento
  • [AVS] — Aviso / Warning (nível 1)
  • [ERR] — Erro crítico (nível 2)
  • (sem prefixo) — Informação normal (nível 0)

🖱️ Botões da Aba Log

BotãoAção Detalhada
🗑 Limpar Apaga todo o conteúdo do log da sessão — tanto o mini-log do Dashboard quanto o log completo desta aba. A operação não pode ser desfeita. Use antes de uma operação específica para capturar somente os logs desejados.
💾 Salvar Log Abre diálogo Salvar Arquivo para exportar o log em formato .txt com data no nome (ex: log_lazarusportable_20260717.txt). Permite arquivar histórico de operações para análise posterior ou envio ao suporte técnico.

12. Aba OPM Online (🌐)

O Online Package Manager permite pesquisar e baixar componentes da comunidade Lazarus diretamente do repositório oficial OPM sem sair do gerenciador portável. A lista exibe: Nome, Versão, Autor, Categoria e Descrição.

🖱️ Controles da Aba OPM

ControleAção Detalhada
Campo 🔎 Buscar pacotes no OPM... Campo de texto para digitar o nome ou palavra-chave do pacote desejado. Deixar vazio e buscar retorna até 30 pacotes populares (o sistema usa "*" como coringa internamente).
🔍 Buscar Consulta o repositório OPM online usando o termo digitado, retornando até 30 resultados. Preenche a lista com os pacotes encontrados. Exibe status de busca e contagem na barra inferior. Se nenhum resultado for encontrado, exibe mensagem informativa.
⬇ Baixar Pacote Selecionado Selecione um pacote na lista e clique. O sistema:
  1. Busca a URL de download oficial do pacote via API OPM.
  2. Realiza o download para a pasta components_ext\ no diretório portável.
  3. Extrai automaticamente o conteúdo do pacote baixado.
  4. Registra o pacote na varredura de pacotes instalados.
  5. Exibe mensagem com as instruções de instalação do .lpk no Lazarus.
A barra de progresso (pbOPM) e o label de status mostram o andamento em tempo real.
💡 Como instalar o pacote baixado na IDE:
  1. Clique em ▶ Lançar Lazarus IDE.
  2. Na IDE, acesse Pacote → Abrir Arquivo de Pacote (.lpk).
  3. Navegue até [PortableDir]\components_ext\, selecione o .lpk e clique em Usar → Instalar.
  4. Após a recompilação automática da IDE, o componente aparecerá na paleta.

13. Aba Manual (📖)

Exibe o manual do usuário em formato texto diretamente dentro da aplicação, disponível offline em qualquer situação. O conteúdo é gerado e carregado automaticamente durante a inicialização da aplicação. Uma cópia em texto plano é salva em MANUAL.txt no diretório portável.

BotãoAção Detalhada
🌐 Abrir Manual no Navegador (HTML) Localiza o arquivo MANUAL.html (buscando em múltiplos caminhos: [PortableDir]\manual\MANUAL.html, [PortableDir]\MANUAL.html, e junto ao executável) e o abre no navegador padrão do sistema para uma visualização mais rica e completa. Se o arquivo não for encontrado, exibe mensagem com o caminho esperado.

14. Tela de Configuração do Banco de Dados (frmConfigDB)

🔐 Acesso Exclusivo de Administrador: Esta tela é acessível apenas pelo Super Administrador (usuário com IS_ADMIN = 1 no banco Firebird). Usuários comuns recebem mensagem "Apenas o Administrador do sistema tem permissão para acessar as configurações do banco de dados" ao clicar em "⚙ Config".

Permite configurar os parâmetros de conexão com o banco de dados Firebird utilizado para autenticação, licenciamento e armazenamento de comprovantes PIX. As configurações são salvas criptografadas no arquivo LazarusConfig\vps_config.ini.

Biblioteca Cliente (DLL)fbclient.dllCaminho completo para a fbclient.dll do Firebird instalada na máquina (ex: C:\Program Files (x86)\Firebird\Firebird_5_0\fbclient.dll).
⚠️ Segurança do vps_config.ini: Todos os valores de conexão são gravados com cifra XOR Hexadecimal (TConfigCrypt). O módulo MigrateAndEncrypt converte automaticamente versões legadas em texto plano para o formato criptografado. Nunca edite o .ini manualmente — use sempre esta tela de configuração.
💡 Erro "arquivo em uso por outro processo": Ocorre quando o IBExpert ou outra ferramenta está conectada em modo Embedded (acesso direto ao arquivo .fdb). Configure o Host como localhost e a Porta como 3050 para forçar a conexão via Socket TCP/IP, eliminando o conflito de acesso exclusivo ao arquivo.

15. Portabilidade e Pen Drive

O Lazarus armazena suas configurações em %LOCALAPPDATA%\lazarus (fixo no computador). O Lazarus Portable Manager redireciona 100% desses dados para:

$(DiretórioDoExe)\LazarusConfig\

Qualquer referência absoluta de caminho nos arquivos XML de configuração (letra de unidade, pasta do usuário) é automaticamente corrigida para apontar para o diretório atual do Pen Drive.

🚀 Guia Passo a Passo: Configurando o Pen Drive pela Primeira Vez

  1. Copie o Lazarus: Copie a pasta completa de instalação do Lazarus do computador (ex: C:\lazarus\) para a raiz ou diretório desejado do Pen Drive (ex: E:\Lazarus\).
  2. Insira o executável: Copie o arquivo LazarusPortable.exe para a mesma pasta onde está o lazarus.exe no Pen Drive (ex: E:\Lazarus\LazarusPortable.exe).
  3. Primeira execução no Pen Drive: Execute o LazarusPortable.exe pelo Pen Drive. O sistema detecta que a pasta LazarusConfig\ está vazia ou ausente e importa automaticamente toda a configuração de %LOCALAPPDATA%\lazarus do PC atual — pacotes, barras de ferramentas, atalhos, temas e preferências.
  4. Patch e Lançamento: Clique em 🔧 Re-Patch Config ou diretamente em ▶ Lançar. Todos os caminhos dos XMLs são atualizados para a nova letra de unidade e o Lazarus abre completamente configurado, pronto para desenvolvimento.
💡 Espaço necessário: Uma instalação completa com FPC e pacotes comuns ocupa aproximadamente 2,5 GB. Recomenda-se usar Pen Drives USB 3.0 de 8 GB ou mais para melhor performance de compilação.
💡 Integração nativa na IDE (LazPortableTools.lpk): Instale o pacote LazPortableTools.lpk na IDE e use o menu Ferramentas → Lazarus Portable Tools para executar Re-Patch e Backups diretamente de dentro do Lazarus, sem sair da IDE.

17. Perguntas Frequentes (FAQ)

Q: O Lazarus abriu sem meus componentes na paleta — o que fazer?

R: Clique em 🔧 Re-Patch Config no Dashboard para garantir que todos os caminhos dos pacotes estão corretos para a unidade atual. Se o problema persistir, vá à aba Perfis e ative o último perfil funcional com ✅ Ativar Perfil.

Q: Ao mover o Pen Drive para outro PC, o Lazarus não abre. O que fazer?

R: A letra de unidade provavelmente mudou (ex: de E:\ para G:\). Clique em 🔧 Re-Patch Config antes de lançar a IDE. O motor de patch detecta a letra atual e corrige todos os XMLs automaticamente.

Q: O banco Firebird deu erro "arquivo em uso por outro processo" — como resolver?

R: Outra ferramenta (ex: IBExpert) está conectada em modo Embedded ao arquivo .fdb. Acesse ⚙ Config (como Admin) e configure Host como localhost e Porta como 3050 para forçar conexão TCP/IP.

Q: Como instalar um pacote baixado via OPM no Lazarus?

R: Após baixar pela aba OPM Online, abra o Lazarus IDE, vá em Pacote → Abrir Arquivo de Pacote (.lpk), navegue até [PortableDir]\components_ext\, selecione o .lpk e clique em Usar → Instalar. A IDE recompilará automaticamente.

Q: Como fazer um backup de emergência das configurações?

R: No Dashboard, clique em 💾 Criar Backup no card de Último Backup. O sistema cria uma cópia completa com data e hora na pasta backup\ do diretório portável (ex: backup\20260717_104500\).

Q: Posso ter múltiplos perfis de Lazarus no mesmo Pen Drive?

R: Sim! Use a aba 👤 Perfis. Cada perfil é um diretório isolado em Profiles\ com seus próprios pacotes, layouts e configurações. Alterne entre eles sem conflito usando ✅ Ativar Perfil.

Q: O que são os arquivos .ppu e .o que o sistema pode limpar?

R: São arquivos de cache do compilador FPC — unidades pré-compiladas (.ppu) e objetos binários (.o). São seguros de deletar: o FPC os recria na próxima compilação. Use 🧹 Limpar Cache quando houver erros estranhos após atualizar o FPC ou componentes.

Q: O QR Code PIX não aparece na tela de pagamento. Isso bloqueia o pagamento?

R: Não. O QR Code é carregado via internet (api.qrserver.com). Sem conexão, o código Copia e Cola continua 100% funcional — use 📋 Copiar Código PIX e cole no seu aplicativo bancário.

Q: Como exportar a lista de pacotes instalados?

R: Vá à aba 📦 Pacotes, clique em 🔄 Varrer para atualizar a lista e depois em 📤 Exportar Lista para salvar um arquivo JSON com todos os pacotes, versões e caminhos.
